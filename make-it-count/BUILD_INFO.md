# Make it Count Web Build

This directory is the directly served GitHub Pages artifact for the visual prototype.

- Source of truth for the cross-platform app: `expo-src/`
- Direct web entry: `index.html`
- Local assets: `expo-src/assets/open-doodles/`
- Visual direction: Warm Editorial Craft / hand-drawn / non-pixel

The static Pages build mirrors the RN/Expo prototype flow and is intentionally dependency-free for reliable direct access on GitHub Pages.
